## 🌐 Live Demo

Try the deployed application:

**[🚀 Open Expense Tracker](https://expense-tracker-web-lemon.vercel.app/)**

The application is deployed using **Vercel** and can be accessed directly from a web browser without installing Python or any dependencies.

> **Note:** The deployed version currently uses SQLite in a serverless environment. Its database storage is intended primarily for demonstration and portfolio purposes. A persistent cloud database can be added for production use.
